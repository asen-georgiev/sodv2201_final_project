# Smart Restaurant Management System

A fullstack web application developed for the SODV2201 Web Development course. The system will allow customers to browse a restaurant menu, place pickup or delivery orders, and book tables or special events. Administrators will manage menu items, orders, and reservations through a dashboard.

## Planned Features

- Menu browsing with search and filters.
- Shopping cart and simulated checkout.
- Table reservations and special event bookings.
- Customer accounts and order history.
- Admin dashboard for managing restaurant operations.
- Chat assistant for menu questions and recommendations.

## Planned Technologies

- **Frontend:** React and Vite
- **Backend:** Node.js and Express
- **Database:** MongoDB, hosted on MongoDB Atlas
- **Version control:** Git and GitHub

## Project Structure

- `client/` — React frontend.
- `server/` — Node.js and Express backend.

## Development Stages

1. **Frontend:** Build the interface and interactions using mock data.
2. **Backend:** Develop the REST API, database integration, authentication, and validation.
3. **Integration:** Connect the frontend and backend, verify functionality, and prepare the final demonstration.

## Current Status
